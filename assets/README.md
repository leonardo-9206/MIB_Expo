# Carpeta de Assets MIB Aduanas

¡Aquí puedes agregar tus imágenes PNG personalizadas si lo deseas!

Por ejemplo:
- Foto real del profesor (Agente D)
- Fotos de las chicas del equipo (Andy, Mich, Emily, Liz, Ilse)
- Ilustraciones de aliens o accesorios

La aplicación web funciona automáticamente con las ilustraciones vectoriales predeterminadas (SVG), por lo que está lista para ejecutarse y desplegarse directamente en GitHub Pages.
